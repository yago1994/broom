Safari Extension

Sweep clutter off any website. Hide the elements you don't want, plant something nice in the empty space, and your changes come back every visit.

Sweeping a page

  1. Click the Broom icon in the Safari toolbar.
  2. Hit Edit this page to enter edit mode.
  3. Hover any element — it highlights as you point.
  4. Click it, then choose Hide to sweep it away.
  5. Press Esc or the toolbar button again to exit edit mode.

Planting in empty spots

  1. After hiding something, the cleared spot becomes plantable in edit mode.
  2. Hover the spot — your cursor turns into a shovel.
  3. Click to plant a random little decoration in the gap.
  4. Use Shuffle to swap it, or broom it away to remove it.

Restoring & managing rules

  • Open the toolbar popup to see every rule for the current site.
  • Tap ♻️ Restore to bring hidden elements back temporarily.
  • Delete a rule from the popup list to undo it permanently.
  • Rules are saved per hostname and re-apply on every page load.

Turn it on

  1. Click to open Safari Extensions.
  2. Enable Broom in the sidebar.
  3. Set its access to Allow on Every Website.
  4. Click the Broom icon in any tab to start sweeping.

Private by default

  • Nothing about your browsing leaves your Mac.
  • Rules live in Safari's local extension storage.
  • No account, no API key, no telemetry.
