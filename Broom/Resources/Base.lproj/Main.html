Safari Extension

Broom

Point at any element on any website, describe what you want changed, and it sticks — every visit.

How to use

  1. Click the Broom icon in the Safari toolbar.
  2. Hit Edit this page.
  3. Click any element to pick it.
  4. Choose Hide to sweep it away.
  5. Rules persist and re-apply on every visit.

Steps to activate

  1. Click to open Safari Extensions.
  2. Enable Broom.
  3. Set access to All Websites.
  4. Use the toolbar popup to start editing a page.

What Broom does

  • Hides elements permanently.
  • Lets you restore hidden elements.
  • Turns swept spaces into plantable spots.
  • Rules apply per-hostname, every page load.

What Broom won't do

  • Will NOT send your browsing data anywhere.
  • Stores rules on-device in Safari storage.
  • Does not require an external API key.
